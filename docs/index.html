How to read this

Option mapping. S = expected annual treatment cost per operator (the EBCT premium), K = deductible, T − t = 1 year, r = short sovereign rate, σ = volatility of the treatment-cost index. Premium C = S·N(d₁) − K·e−rT·N(d₂). With K = 0 and r = 0 the option premium equals the EBCT premium.

Limits. Treatment costs are not traded, so the formula is a lognormal pricing model with r as the discount rate, not an arbitrage price. Defaults for K and r are illustrative. Gross premiums would add expense and risk loadings.
